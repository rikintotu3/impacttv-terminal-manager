# impactTV 端末管理（PWA版）

**アプリ**：[https://impacttv.kaino.co.jp/](https://impacttv.kaino.co.jp/)

[配布用QRコード](qr-code.png)にはアプリURLだけが入っています。合言葉は含みません。

各端末の黄色シール（バーコード）をスマホで読み取り、状態・設置場所・履歴を記録するアプリです。「ホーム画面に追加」すると、アプリのようにワンタップで開けます。

## 現在の構成：v2.2.0（2026-09-25）

- Google Apps Script（GAS）の本番APIへ接続する設定です。記録の保存先は非公開のGoogleスプレッドシートです。
- 本番では `DEMO_MODE: false` を指定しています。接続設定の不足や取得失敗時はエラーを表示し、デモへ自動で切り替わりません。
- 本番APIの初期設定、未認証の台帳取得の拒否、画面からの登録と再読み込み後の保存を確認しました。スマホ実機のカメラ読み取りは利用端末で確認してください。
- 本番の合言葉は管理者用スプレッドシートの **「設定」シート B2** で管理します。値をこの文書、公開ファイル、QRコードへ掲載しないでください。
- 店舗利用者は合言葉でログインします。Googleアカウントは不要です。台帳とApps Scriptプロジェクトの共有範囲は管理者だけに限定します。

### v2.2.0 の変更

- 本部専用の認証と「廃棄する（本部専用）」を追加しました。通常の店舗用合言葉だけでは廃棄を確定できません。
- 設定から本部用合言葉で認証すると、最大8時間、同じタブ・端末で本部操作ができます。作業後は「本部認証を終了する」を押してください。
- 端末の詳細で「廃棄する（本部専用）」を押し、確認結果・廃棄理由を入力して最終確認します。台帳・履歴・元の症状は残ります。契約の解約は別途必要です。
- 廃棄済み端末は棚卸・長期未確認の対象から外れます。古い棚卸下書きでも状態を上書きしません。廃棄済み端末の変更と取り消しもサーバー側で本部認証を確認します。
- 本部用合言葉は管理台帳の「設定」→「本部用合言葉」で管理し、本部担当者だけに案内してください。値は公開ファイル・チャット・QRへ掲載しません。変更すると本部認証は直ちに無効になります。
- バックエンドはAPI v1.2.0です。本部認証は共有合言葉による権限確認で、個人アカウント認証ではありません。

### v2.1.0 の変更

- 本番保存先への接続を設定し、本番環境でのデモへの自動切替を無効にしました。
- アプリとService Workerのバージョンを更新しました。
- バックエンドは本番用に更新した `Combined.gs` と明示的な権限設定を使います。公開GETは中立な稼働確認だけを返し、台帳や認証情報を返しません。

v2.0.1 で対応した、接続設定の更新、故障端末の新規登録時の症状選択、他アプリのキャッシュを保護する処理、ホーム画面からの起動設定も引き継いでいます。

## スマホで使う

1. SafariまたはChromeで[アプリ](https://impacttv.kaino.co.jp/)を開きます。
2. 本部から案内された合言葉と、記録者のお名前を入力して「はじめる」を押します。
3. 「ホーム画面に追加」すると、次回からアイコンで開けます。

| スマホ | ホーム画面への追加 |
|---|---|
| Android／Chrome | アプリの設定画面にあるインストールボタン、またはブラウザのメニュー |
| iPhone／Safari | 共有ボタン →「ホーム画面に追加」 |

バーコードの読み取りはスマホ内で行います。読み取りのために写真を送信することはありません。かざすだけの連続読み取りを標準で使い、対応しない環境では撮影方式に切り替わります。読み取れないときは「番号を入力」を使えます（下4桁で検索できます）。

記録の保存と最新情報の取得にはインターネット接続が必要です。画面がキャッシュから開いても、保存完了を確認するまでは記録済みとして扱わないでください。

## しくみと公開ファイル

| 役割 | 置き場所 |
|---|---|
| 画面 | 会社ドメインのHTTPSホストで公開する静的PWA |
| 認証・保存API | 管理者として実行するGASウェブアプリ |
| 台帳・設定 | 管理者だけが開けるGoogleスプレッドシート |
| 故障写真 | GASが作成・使用する非公開のDriveフォルダ |

アプリはGASの `/exec` URLへ直接POSTします。APIが公開URLであっても、台帳操作にはアプリの認証が必要です。写真フォルダは自動で一般公開されません。

| 公開ファイル | 役割 |
|---|---|
| `index.html` | アプリ画面・読み取り・通信 |
| `config.js` | 接続先とデモ利用可否 |
| `manifest.webmanifest` / `sw.js` | ホーム画面への追加と画面ファイルのキャッシュ |
| `demo.js` | 明示的にデモを有効にした検証環境だけで使う架空データ。本番では使いません |
| `icons/` | アプリアイコン |
| `qr-code.png` | 合言葉を含まない配布用QRコード |

公開用の正本はGit管理された `_deploy/` です。実台帳、記録者情報、合言葉、トークン、バックエンドの管理用ファイルを混ぜないでください。ローカルの `app/demo.js` や `app/dist/` は従来の実台帳を使った検証用のため、そのまま公開しないでください。

## 管理者向け：本番バックエンドの設定

この構成は**スタンドアロンのApps Scriptプロジェクト**を使います。従来のHTML `index` をGASへ配置する手順は不要です。

1. 管理者だけが編集できるApps Scriptプロジェクトと、非公開の保存用スプレッドシートを用意します。
2. 非公開の管理用資材から、本番向け `Combined.gs` を単一のソースとして配置し、`appsscript.json` の権限設定を適用します。分割版の `Code.gs` と `Admin.gs` を重ねて配置しないでください。
3. 保存対象が準備済みの本番台帳であることを管理者が確認し、エディタで **`setupProduction()`** を実行して初回承認を完了します。既存の異なる保存先が設定されている場合は処理を止めます。
4. 完了後、合言葉は台帳の「設定」B2で確認・変更します。実行ログには合言葉を出しません。スタンドアロン版ではスプレッドシートの管理メニューは追加されません。
5. ウェブアプリとして「実行するユーザー：自分」「アクセスできるユーザー：全員」でデプロイし、発行された `/exec` URLをフロントエンドの接続設定に指定します。台帳やプロジェクト自体の一般公開は不要です。

`setupProduction()` は実行者と実効ユーザーのメールが空でなく一致することを確認します。これはプロジェクトのアクセス制限の代わりにはなりません。プロジェクトの編集権限は管理者に限定してください。

## 管理者向け：公開・更新

公開するのは、上の公開ファイル表にある静的ファイルです。秘密情報、管理用スクリプト、実データ、開発用依存ファイルを配置しないでください。カメラとService WorkerのためにHTTPSが必要です。

本番の `config.js` は次の形式です。URLはデプロイ済みAPIのものに置き換えます。

```js
window.ITV_CONFIG = {
  API_URL: 'https://script.google.com/macros/s/DEPLOYMENT_ID/exec',
  DEMO_MODE: false,
};
```

`API_URL` が空でも、本番設定ではデモを起動しません。検証用デモを使う場合は、本番から分けた検証環境で明示的に有効にし、架空データだけを使用してください。

接続設定はオンライン時に毎回取得します。設定変更後はオンラインでアプリを開き直してください。画面・アイコンなどを変えた場合はService Workerのバージョンも更新します。オフライン時は直近の正常な設定を使える場合がありますが、記録の保存には通信が必要です。

公開切替の確認では、指定したテスト用の端末を登録し、ページを開き直しても同じ記録が見えること、別のブラウザやスマホからも取得できることを確認します。実データを公開ファイルや検証ログへ転記しないでください。

## 困ったとき

| 症状 | 対処 |
|---|---|
| 接続先の設定エラーが出る | 管理者が `config.js` の本番API URLを確認します。本番ではデモに切り替わりません |
| 保存できない・最新情報にならない | ネットワークを確認し、オンラインで開き直します。保存完了が出たか確認してください |
| カメラが開かない | HTTPSで開いているか確認します。LINE／LINE WORKS内なら外部ブラウザで開き、カメラを許可してください |
| iPhoneでホーム画面への追加が見つからない | Safariの共有ボタンから追加します |
| 古い画面のまま | 一度閉じてオンラインで開き直し、設定画面のバージョンが `2.2.0` になったか確認します |
| バーコードが読めない | 明るい場所でシール全体を大きく写します。難しい場合は「番号を入力」を使います |
| 読み取り機能を読み込めない | ネットワークで `fastly.jsdelivr.net` が遮断されていないか確認します |
| 合言葉の確認が必要と表示される | 合言葉が変更された可能性があります。本部に確認して再ログインしてください |

合言葉をURLへ入れたQRコードは配布せず、アプリURLだけのQRコードと、組織内で案内する合言葉を使ってください。
